## Featured Projects

### Meal Ticket Management System

Full-stack enterprise application developed during my software development internship.

Built with:

- Java
- Spring Boot
- React
- TypeScript
- MySQL
- REST APIs
- Spring Data JPA
- MyBatis-Plus
- Maven

Because the project was developed in a company intranet environment, the source code and internal screenshots are not publicly available.

### Airline Management System

Full-stack airline management platform developed for ECSE 321 at McGill University.

Built with:

- Java 21
- Spring Boot
- Vue.js 3
- Vite
- Tailwind CSS
- PostgreSQL
- Spring Data JPA
- Spring Security
- JWT
- REST APIs
- Pinia
- Axios
- Docker
- JUnit
- JaCoCo

The system supports flight search, booking, payments, cancellations, crew assignments, role-based workflows, and airline administration.

Project repository:

https://github.com/McGill-ECSE321-Fall2025/group-project-group-8

### AquaX Autonomous Robotic Firefighter

Autonomous robotic firefighting system developed for ECSE 211 at McGill University.

The project used:

- Python
- LEGO + BrickPi
- EV3 motors and sensors
- Ultrasonic sensing
- Color detection
- Gyro feedback
- Odometry
- Hardware-software integration
- Iterative testing and calibration

The robot was designed to autonomously navigate a simulated indoor environment, detect fires and obstacles, deploy fire-suppression materials, and return to its starting position.
